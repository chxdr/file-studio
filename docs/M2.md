## What works

**The window:**
- an always-visible address bar that works as both a breadcrumb and a text field, with fuzzy and frecency completion
- tabs, single or dual pane
- a sidebar with favourites (pin, remove and reorder), volumes and eject

**The views:**
- list and column views, with 100k rows staying smooth
- type-to-select and filter as you type

**Operations:**
- the operation queue, the conflict sheet and the held-⌘ shortcut overlay
- context menus defined by the core

**Setup and settings:**
- first-run setup with a power tour, hints and Settings
- Standard and Vim keymaps

**Safety.** Everything below is enforced in Rust and tested:
- **No silent moves (F-023).**
  - Dragging in the sidebar only reorders references.
  - Moving a standard folder asks first, with Cancel as the default.
  - Every move shows a toast with Undo.
  - Drops go to the folder highlighted at mouse-up.
- **The independent audit's 14 findings are all fixed,** each with a regression test (`docs/SAFETY-AUDIT.md`, `crates/fstudio-core/tests/safety_audit.rs`). The headline fixes:
  - Confirmations act only on what the dialog named.
  - Redo checks identities and never replays across a relaunch.
  - Undo never silently recreates a missing folder, and undoing a Trash restores only that item.
  - Key auto-repeat repeats only movement.
  - Paste uses the system pasteboard.
  - Trash, Undo and Redo show toasts.
- **App-level proofs.** `scripts/safety-proofs.sh` drives the real Debug app against throwaway home folders, with a scratch Trash. There are 9 proofs and all 9 pass.

**M2 gaps closed overnight:**
- Window preferences now live in core settings, migrated once from the old storage.
- The Settings controls that did nothing are now wired.
- The address field no longer overlaps the subtitle. I checked this myself with a screenshot.
- ⌘X then ⌘V moves the item, and Undo puts it back. This is proven in the app.
- Status messages clear on the next selection or folder change.
- F5 and F6 show in the menus.
