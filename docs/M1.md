## Known issues and gaps

- **Warm cache only.** Cold-cache numbers need `sudo purge`. M0's cold listing of 100k entries on a disk image was about 880 ms.
- **No real external drive yet.** All cross-volume numbers use a disk image on the internal SSD.
- **Untested:** the system Trash in automated tests (it worked by hand through the CLI), and real iCloud placeholders (dropped at the user's request).
- **`fstudio ops cancel`** can't cancel an operation interrupted by an earlier run until it has been resumed. This is a small `fstudio-ops` fix.
- **FFI types.** The ops and path types use `PathBuf` and aren't all serde. M2's UniFFI layer needs `String` mirrors.
- **Benchmark fixtures** (about 1.3 GB) are cached in `$TMPDIR/fstudio-bench-fixtures` for reuse. Delete the folder to reclaim the space.
