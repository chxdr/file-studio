## Surprises worth knowing

- **`copyfile(COPYFILE_ALL)` silently de-sparses files:** a 32 KiB sparse file becomes 1 GiB. You must ask for `COPYFILE_DATA_SPARSE`.
- **Plain `clonefile` and `cp -c` drop ACLs.** `copyfile(ALL|CLONE)` keeps them.
- **A `deny delete` ACL blocks renaming the temporary copy into place**, so ACLs are applied after the rename.
- **The "5 GB/s" copy figures are the page cache.** Copy speed has to be compared on durable time.
- **iCloud placeholders** can be detected for free from the listing (the `SF_DATALESS` flag). None of the metadata calls we use trigger a download.
- **APFS keeps names exactly as given** (NFC or NFD), but matches them regardless of normalisation. Two visually identical names can't coexist.
- **Marta crashed twice on a `file://` path**, so our parser gets fuzz tests.
